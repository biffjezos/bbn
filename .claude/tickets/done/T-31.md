## Summary

`modal-block` and `modal-delete` were incorrectly included globally in `base.html`. They are page-scoped modals (block/unblock action, account deletion) that should only appear on pages that use them.

## What Was Done

- Removed `{% include "partials/modal-block.html" %}` and `{% include "partials/modal-delete.html" %}` from `base.html`
- Added `{% include "partials/modal-block.html" %}` to `pages/index.html`, `pages/messages-thread.html`, `pages/profile-view.html`
- Added `{% include "partials/modal-delete.html" %}` to `pages/settings.html`
