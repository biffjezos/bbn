## Summary

Replaced Jekyll/GitHub Pages static site with a Rust Axum server that serves SSR HTML via Tera templates and proxies all API/WS calls to the gateway.

## What Was Done

### Phase 1 — Server scaffold
- New `server` crate added to workspace (Axum, Tera, reqwest, tokio)
- HTTP + WebSocket reverse proxy to gateway
- `Dockerfile.server` created
- All 8 non-server Dockerfiles updated with server workspace stub

### Phase 2 — Tera template migration
- All 9 Jekyll Liquid templates converted to Tera (`base.html`, 7 partials, 9 page templates)
- `window.BOOMBOOM_API_URL` / `window.BOOMBOOM_BASE` removed from base template
- `api.js` `API_BASE` changed from `window.BOOMBOOM_API_URL` to `''`
- `asset_version` variable for cache-busting

### Phase 3 — Server-side route guards
- `guards.rs`: `check_auth`, `require_user`, `require_admin` using `jsonwebtoken`
- `JWT_SECRET` env var required; protected routes return 302 on missing/invalid token
- `auth.js`: `setBbnCookie` / `clearBbnCookie` added to set `bbn_tok` on login/logout
- Client-side inline guard script removed

### Phase 4 — Minimal SSR data injection
- `guards.rs`: `AuthContext.raw_token` added for gateway forwarding
- `fetch_me` helper: calls `{GATEWAY_URL}/api/users/me` (3 s timeout, graceful None)
- `page_profile` and `page_settings` inject `ssr_me` into Tera context
- `profile.html`: renders nickname/age/sex/bio on first paint
- `settings.html`: renders tier/account_type in accountInfoWrap

## Env Vars Required (Railway — server service)
- `JWT_SECRET` — shared with authority-service
- `GATEWAY_URL` — internal Railway URL of gateway service
- `GATEWAY_ALLOWED_HOST` — public domain (for Host header validation)
- `ASSET_VERSION` — cache-buster string (e.g. `v1.0`)
- `TEMPLATES_DIR` — path to Tera templates directory
