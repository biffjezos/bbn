## What was done

Diagnosed (Phase 1) and fixed (Phase 2) in session 2026-03-31.

**Root cause:** `admin.js` existed and was functional but was never loaded. The Tera
`admin.html` template had a placeholder comment but no `<script>` tag. `admin.js`
is a non-module legacy script that uses `window.Auth`, `window.Api`, and
`window.__authReady` — all set by `boomboom.js` at runtime.

**Fix:** In `boomboom.js`, after `await window.__authReady`, check for `#adminPanel`
and dynamically inject `<script src="/scripts/admin.js">`. By the time the script
loads, `window.Auth`, `window.Api`, and `window.__authReady` (already resolved) are
all available. `admin.js` uses `window.__authReady.then(initAdmin)` which fires
correctly on an already-resolved promise.
