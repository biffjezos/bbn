## What was done

Wired the existing `#notifBanner` container (below navbar) to show a dismissable warning banner whenever a rate-limit (HTTP 429) is encountered.

**Changes:**
- `ui/scripts/auth.js`: fires `Auth.onRateLimited?.()` when the retried guest-init call also returns 429
- `ui/scripts/app.js`: added `showRateLimitBanner()` helper (outer scope, deduplication by class); wired `Auth.onRateLimited` hook; added `err.status === 429` checks in login and register catch blocks

Banner uses Bootstrap `alert-warning`, is dismissable, and includes a link to `/donate/`.
