## What was done

**Phase 1** (completed 2026-03-23): `meta_settings` collection seeded via migration `009_admin_settings`
with 9 editable keys (rate limits, message TTL, favourite expiry, location update distance,
WS delta). Admin Settings tab wired up with editable inputs and save buttons.

**Phase 2** (completed 2026-03-24): No new editable keys were added — the remaining candidates
(`SHARD_SIZE_M`, MongoDB index TTLs) were ruled out as unsafe to make runtime-editable.
Instead, location-service config (shard size, TTL, update interval/distance, sweep interval,
nearby limit, store type) is now surfaced as a **read-only** "Location" section in the admin
Settings tab. Data comes from `GET /api/admin/location-config` (gateway → location-service
`/admin/config`), which returns the live env-var-based config.
