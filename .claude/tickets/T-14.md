**Status:** Deferred — no tier infrastructure exists for managers yet. Venue limit currently set to 9999 (effectively unlimited). Manual approval process keeps abuse low-risk for now.

---

## Idea

Combine the user `tier` concept with manager roles so that a "regular manager" can manage up to N venues and a "premium manager" can manage more. Requires:

1. A manager-specific tier dimension (separate from or layered on top of existing user tiers).
2. The authority-service to know about manager quotas.
3. `POST /manager/venues` to query the manager's quota before allowing creation.

---

## Prerequisites

T-08 (Authority service) should land first so there is a single source of truth for roles + tiers before adding a second tier dimension.
