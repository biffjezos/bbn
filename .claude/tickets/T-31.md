## Problem

`modal-block` and `modal-delete` are currently included globally in
`services/server/templates/base.html`. They should be page-scoped: only
rendered in the DOM on pages that can actually trigger them.

The original `ui/_layouts/default.html` did not include them at all —
this was an oversight (they were never in the DOM in the Jekyll build either).

## Fix

Remove both `{% include %}` lines from `base.html` and add them to
the specific page templates that need them:

| Modal | Pages |
|---|---|
| `modal-block.html` | `pages/index.html`, `pages/messages-thread.html`, `pages/profile-view.html` |
| `modal-delete.html` | `pages/settings.html` |

## Definition of Done

- `base.html` does not include modal-block or modal-delete
- Each page template includes only the modals it needs
- `cargo build -p server` passes
