## Problem

Owner reports `/admin` page is empty after the Tera server migration. Admin JS functionality is likely not loaded — `admin.js` may be dead code that was never wired into the new Tera template system.

## Investigation needed

1. Check `services/server/templates/pages/admin.html` — is `admin.js` or equivalent referenced?
2. Check `ui/scripts/` — does `admin.js` exist, and if so, is it an ES6 module or a legacy script?
3. Check whether the admin page renders the correct Tera template (`pages/admin.html`) — server route `/admin/` does exist in `main.rs:288`.
4. Determine whether admin functionality was migrated from Jekyll to Tera or was simply not migrated.

## Implementation plan

### Phase 1 — Diagnose
- Read `services/server/templates/pages/admin.html`
- Read `ui/scripts/admin.js` if it exists
- Confirm what is and isn't wired

### Phase 2 — Fix
- Wire admin.js into the Tera admin page (if it exists and is functional)
- Or create/migrate admin functionality if missing
