## Problem

Several constants that affect user experience are currently hardcoded in services and cannot be changed without a redeploy.

---

## Proposed schema

```
meta: {
  key:             string   // e.g. "message_ttl_ms"
  value:           any
  type:            "number" | "string" | "boolean"
  scope:           "admin" | "user" | "system"
  description:     string
  restartRequired: boolean
  affects:         string   // service name or "ui"
}
```

## Phase 2 — Remaining keys

Keys not yet wired up or still open:

- Location sharding settings (`SHARD_SIZE_M`) — deferred with T-20 Phase 5.
- Any admin-scope global defaults that differ from per-user T-07a preference values.

**NOT safe to make runtime-editable:**
- MongoDB index TTLs (sessions `15 min`, locations `10 min`) — require `collMod` or migration; track as a separate migration step.
- Everything crypto, bcrypt cost, JWT structure, CORS — hard-code, no exceptions.
